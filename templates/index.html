HOW TO USE✕

Upload any IUE SWP spectrum as a plain .txt file with two whitespace-separated columns: wavelength (Å) and flux.

Demo loads Spectrum 70 — a real 3C273 archival observation — so you can explore the pipeline without your own file.

Once submitted, the pipeline fits a power-law continuum, searches 5,600 Gaussian candidate models, refines with scipy, and returns all line statistics instantly.

SUMMARY TABLE COLUMNS✕

Δλ — wavelength shift from rest frame. Velocity — Doppler offset in km/s (v = cΔλ/λ_rest).

FWHM — full width at half maximum, converted to km/s via 2.355σ·c/μ.

Flux — integrated line flux A·σ·√(2π). EW — equivalent width relative to continuum.

SNR — detection significance = Flux / σ_Flux. χ²red — reduced chi-squared goodness of fit.

// QUALITY CONTROL & SELECTION DIAGNOSTICS
QUALITY CONTROL✕

Each check is a pass/warn/fail gate. SNR must exceed the threshold for a reliable detection. χ²red near 1 indicates a good fit; far above 1 = poor fit or underestimated noise.

Composite score = 0.35·χ² + 0.25·peak + 0.20·left wing + 0.10·right wing + 0.10·SNR. Higher = better model.

ACCEPTED means all primary gates passed. REJECTED spectra still report parameters but should be treated with caution.
