Open questions for the teacher
==============================

1. C IV when one Gaussian is enough
   In the reference sheet (CT-3C273-LUCK-EMMY.xls) some spectra have C IV split
   into CIV-N + CIV-B, and others fitted as a single Gaussian ("CIV-T" / "CIV").
   Should the pipeline:
     (a) always split C IV into narrow + broad, or
     (b) use a single Gaussian (CIV-T) when the data do not need two, e.g. when
         the two-Gaussian fit is not clearly better (ΔBIC < 10)?
   Currently: always split (a). ΔBIC is reported for every spectrum, so (b)
   can be switched on later.
